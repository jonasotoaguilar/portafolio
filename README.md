# Jonathan Soto — Portfolio

Personal portfolio for Jonathan Soto (jonasotoaguilar), Backend & Full-Stack Engineer. A static, Persona-3-inspired single-page site built with Astro 7, showcasing four real projects for recruiters and developers.

## Quick Path

1. Clone the repository.
2. Install dependencies with pnpm (Node >= 24 required).
3. Run the dev server.
4. Open http://localhost:4321 and verify the Hero renders with the three background layers (glow, scanlines, canvas).

## Quick Start

```bash
# Clone
git clone git@github.com:jonasotoaguilar/portafolio.git
cd portafolio

# Install
pnpm install

# Run
pnpm dev
```

### Local Development

```bash
pnpm dev      # dev server at http://localhost:4321
pnpm test     # Vitest unit tests
pnpm build    # production build to dist/
pnpm preview  # preview the production build locally
```

## What Is This?

A single-page static portfolio: Hero with the subtitle "Backend & Full-Stack Engineer" (focus on Go, TypeScript, Python, clean architecture, and API design), a Featured Work grid, Projects, Skills, and a Contact call-to-action, plus a 404 page. Navigation anchors: Featured Work, Projects, Skills, Contact.

It presents four real projects: ServiceFlow (Next.js 16/TypeScript/React 19/Tailwind CSS v4/Appwrite/Docker service-order and ticket management platform, open source), WealthQuest (Unity/C# thesis game, live at https://jonasotoaguilar.itch.io/wealthquest), EventCommerce (Python FastAPI/SQLAlchemy 2 async event-driven commerce backend, open source), and Fintual Sensor (JavaScript Fintual savings-goal sensor, an open-source BlendedGames-bGames organization contribution).

The visual identity is Persona-3-inspired: a near-black navy base, a breathing radial blue glow, CRT scanlines, and a Canvas 2D particle/fog layer as the living background. Display typography is self-hosted (Anton and Bebas Neue). The site is fully static — no backend, no database, no build-time API calls — so every page ships as plain HTML with a strict JavaScript budget.

## Features

- **Static site generation**: Astro 7.2.0 with Markdown Content Collections (typed schemas, zero server state).
- **Persona-3 aesthetic**: CSS animated radial glow, CRT scanline overlay, Canvas 2D particles/fog driven by a `requestAnimationFrame` game loop.
- **Native view transitions**: Astro `<ClientRouter/>` replaces an SPA router; the canvas layer persists via `transition:persist`.
- **Self-hosted fonts**: Anton and Bebas Neue via `@fontsource` (no external font CDN).
- **SEO**: descriptive title, JSON-LD `Person` with `sameAs` links, sitemap generated by `@astrojs/sitemap`.
- **Quality toolchain**: Vitest unit tests, Playwright E2E, Stryker mutation-readiness check, Biome lint/format, Lefthook git hooks.

## Usage

### Adding or Editing Content

All site content lives in `src/content/` as Markdown. Add or edit a project entry and the Featured Work grid and Projects section pick it up at build time.

### Building

```bash
pnpm build && pnpm preview
```
