# Jonathan Soto — Portfolio

Personal portfolio for Jonathan Soto (jonasotoaguilar), Backend & Full-Stack Engineer. A static, Persona-3-inspired game-menu portfolio built with Astro 7: the root route is a full-screen game menu of five route items, each swapping the complete view to its own static page, showcasing four real projects for recruiters and developers.

## Quick Path

1. Clone the repository.
2. Install dependencies with pnpm (Node >= 24 required).
3. Run the dev server.
4. Open http://localhost:4321 and verify the game-menu shell renders five route items over the layered background (glow, scanlines, canvas, figure layer).

## Quick Start

```bash
# Clone
git clone git@github.com:jonasotoaguilar/portafolio.git
cd portafolio

# Install
pnpm install

# Run
pnpm dev
```

### Local Development

```bash
pnpm dev      # dev server at http://localhost:4321
pnpm test     # Vitest unit tests
pnpm build    # production build to dist/
pnpm preview  # preview the production build locally
```

## What Is This?

A static game-menu portfolio: the root route `/` is a full-screen game shell with five giant, diagonally staggered menu items — ABOUT, RESUME, PROJECTS, SKILLS, CONTACT — navigable with ArrowUp/ArrowDown + Enter. Selecting an item changes the complete view to its own static route (`/about`, `/resume`, `/projects`, `/skills`, `/contact`); Escape or Browser Back returns to the menu. A persistent colorful indicator follows keyboard navigation (`data-active` + `aria-current`), and key hints plus the ambient-audio mute toggle sit in a fixed bottom-right control cluster. An original decorative figure/artifact layer renders over the animated background on every route (zero JavaScript, hidden from assistive tech).

It presents four real projects: ServiceFlow (Next.js 16/TypeScript/React 19/Tailwind CSS v4/Appwrite/Docker service-order and ticket management platform, open source), WealthQuest (Unity/C# thesis game, live at https://jonasotoaguilar.itch.io/wealthquest), EventCommerce (Python FastAPI/SQLAlchemy 2 async event-driven commerce backend, open source), and Fintual Sensor (JavaScript Fintual savings-goal sensor, an open-source BlendedGames-bGames organization contribution).

The visual identity is Persona-3-inspired: a near-black navy base, a breathing radial blue glow, CRT scanlines, a Canvas 2D particle/fog layer, and the original figure layer. Display typography is self-hosted (Anton and Bebas Neue). The site is fully static — no backend, no database, no build-time API calls — so every page ships as plain HTML with a strict JavaScript budget.

## Features

- **Static site generation**: Astro 7.2.0 with Markdown Content Collections (typed schemas, zero server state).
- **Game-menu shell**: full-screen diagonal-staggered menu with a persistent keyboard-active indicator, real route links, and zero-JS readability; each view is its own static page.
- **Persona-3 aesthetic**: CSS animated radial glow, CRT scanline overlay, Canvas 2D particles/fog driven by a `requestAnimationFrame` game loop, and an original inline-SVG figure/artifact layer per route.
- **Native view transitions**: Astro `<ClientRouter/>` replaces an SPA router; the canvas layer and the control cluster persist via `transition:persist`.
- **Ambient audio (bring your own)**: plays a licensed track you place at `public/audio/background.mp3` — never bundled; keyboard-operable mute toggle with `aria-pressed`, gesture-unlocked playback, persisted preference, graceful no-track state.
- **Self-hosted fonts**: Anton and Bebas Neue via `@fontsource` (no external font CDN).
- **SEO**: per-view titles, JSON-LD `Person` with `sameAs` links, sitemap generated by `@astrojs/sitemap`.
- **Quality toolchain**: Vitest unit tests, Playwright E2E, Stryker mutation-readiness check, Biome lint/format, Lefthook git hooks.

## Usage

### Adding or Editing Content

All site content lives in `src/content/` as Markdown or YAML. Add or edit a project entry and the PROJECTS view picks it up at build time; the resume, skills, and site config are typed YAML collections.

### Ambient Audio (bring your own licensed track)

The site ships no bundled soundtrack. To enable optional background music, place a single MP3 you are licensed to use at `public/audio/background.mp3` and rebuild:

```bash
cp your-licensed-track.mp3 public/audio/background.mp3
pnpm build
```

The mute control (bottom-right, labeled "Sound: Off" / "Sound: On") is keyboard-operable and always reachable. With no track file the site stays silent and the control renders disabled; with a track, playback starts only after your first pointer or keyboard gesture, fades in, and the muted preference persists across reloads and navigation. Never bundle copyrighted music — the full contract lives in `public/audio/README.txt`.

### Building

```bash
pnpm build && pnpm preview
```
