# v0.1.6 — Smoother navigation, stable ambient, corrected authorship

Patch release over PR #43 (issue #44): client-route navigation is now owned by a single transition, the ambient background stays stable across routes and paints without delaying load, the brand label names the role, and the WealthQuest credit reads exactly `Author Jonathan Soto`.

## What changed

### Smooth client navigation

Astro's 250ms root fade is now the single owner of ClientRouter navigation. Incoming `[data-entrance]` nodes finalize visible pre-paint at `astro:after-swap`, and `astro:page-load` skips the GSAP entrance on navigated documents — the authored 24px/620ms cascade runs on initial load only. Persisted WaterField and bg-word hosts stay stable, so navigating no longer re-runs ambient motion. (PR #43)

### Stable ambient background and initial loading

The decorative WaterField stays painted at its CSS opacity from first paint — never hidden from opacity 0 — so it cannot delay LCP; only the compositor-safe scale settle animates. Per-variant bg-word settle matches the persisted final (normal 0.045, cyan 0.07), so initial and navigated renders agree with no route jump. The WaterField image now loads eager. (PR #43)

### Accessible branding

The home brand link's accessible name is now "Jonathan Soto, Backend Engineer — Home", stating the role for assistive technology. (PR #43)

### WealthQuest authorship correction

About and experience data now credit the thesis exactly as `Author Jonathan Soto. Published May 2025`, replacing the previous co-author wording; `sole author` / `co-author` phrasing is asserted absent by E2E. (PR #43, closes #44)

### Generated trace-format fix

The scroll-trace summary generator normalizes its Markdown output through the repo's canonical formatter, so generated traces keep `pnpm run format:check` green. (PR #43)
